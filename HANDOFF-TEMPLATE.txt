Fusion gateway invitation handoff

Give each developer their own private invitation through an approved secret-sharing channel.
Do not put the invitation or any token into chat, source control or public documentation.

Developer steps:
  ./setup developer join --invite /path/to/personal-invitation.json
  ./setup doctor
  claude

Expected route: Claude Code → ACA (LiteLLM → Fusion).
The invitation contains a personal gateway key, never a GitHub PAT.
No Claude subscription sign-in is needed for this configuration.
Administrator reference: docs/ADMINISTRATOR.md.
