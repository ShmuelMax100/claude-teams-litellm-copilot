Personal Fusion invitation

Use ./setup admin enroll to generate a private fusion-gateway-v1 invitation.
It binds an exact gateway user ID and one authorized Fusion tier to a personal gateway key.
It contains no GitHub PAT, provider connection or alternate-route policy.
Transfer the generated file privately and run:
  ./setup developer join --invite /path/to/personal-invitation.json
Never construct or publish a real credential in this example.
